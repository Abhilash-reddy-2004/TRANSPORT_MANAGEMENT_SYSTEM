# 🚍 Transport Management System

A web-based **Transport Management System** developed using **PHP, MySQL, HTML, CSS, and JavaScript**. This application allows users to manage transport bookings while providing an administrative interface for managing the system efficiently.

---

## 📌 Features

* User Registration and Login
* Admin Login
* Transport Booking Management
* View Available Transport Services
* Manage Customer Information
* Booking History
* MySQL Database Integration
* Responsive Web Interface

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP
* **Database:** MySQL
* **Server:** Apache (XAMPP)

## 🚀 Installation

1. Clone the repository:

```bash
git clone https://github.com/Abhilash-reddy-2004/TRANSPORT_MANAGEMENT_SYSTEM.git
```

2. Move the project folder into:

```text
C:\xampp\htdocs\
```

3. Start **Apache** and **MySQL** using the XAMPP Control Panel.

4. Open **phpMyAdmin** and create a database named:

```text
transport
```

5. Import the `transport.sql` file into the database.

6. Launch the application in your browser:

```text
http://localhost/transport/
```
